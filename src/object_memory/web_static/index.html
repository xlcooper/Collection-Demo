VISUAL OBJECT MEMORY

Collection
Demo

从场景图片到可持续对象记忆

上传一组场景图片后，Qwen3-VL 会提出值得观察的完整物体，SAM3 按文本目标定位和分割候选， 再由 Qwen3-VL 判断候选有效性与对象身份。对象档案和跨视角观测最终写入 SQLite，页面同步呈现完整过程、耗时与结果证据。

默认视觉语言模型 Qwen3-VL-8B-Instruct-FP8
默认分割模型 SAM3 0.1.0 · BF16 · 文本阈值 0.4
服务器与推理调度基线 AutoDL · RTX 4090 24 GB · 单卡顺序加载
