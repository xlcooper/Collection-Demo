## 2. 环境重建步骤

本节仅用于新服务器或环境损坏后的重建。当前服务器无需执行。

### 2.1 Conda 基础环境

```bash
cd /root/autodl-tmp/Collection-Demo
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy

conda env create \
  --prefix "$PWD/.conda/envs/object-memory-demo" \
  --file environment.yml

conda activate "$PWD/.conda/envs/object-memory-demo"
```

环境已存在时，将 `conda env create` 换成：

```bash
conda env update \
  --prefix "$PWD/.conda/envs/object-memory-demo" \
  --file environment.yml
```

### 2.2 普通 Python 依赖

```bash
python -m pip install --timeout 120 --retries 10 -r requirements.txt
```

### 2.3 SAM3 源码

已有 `sam3.pt` 只是权重，仍需安装源码。网络加速只用于这个 GitHub 步骤：

```bash
source /etc/network_turbo
python -m pip install \
  --no-deps \
  --no-build-isolation \
  --timeout 120 \
  --retries 10 \
  -r requirements-sam3.txt
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy
```

三个步骤相互独立，哪一步失败只重跑哪一步。

## 4. 下载 Qwen 权重

在项目环境中执行：

```bash
export HF_HOME="$PWD/weights/qwen"
export HF_HUB_CACHE="$HF_HOME/hub"
source /etc/network_turbo
hf download Qwen/Qwen3-VL-8B-Instruct-FP8
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy
```

`weights/qwen` 是 Hugging Face 缓存根目录，实际模型位于其 `hub/` 子目录。下载中断后重复同一条 `hf download` 命令即可复用缓存并继续。

## 6. 按需复现冒烟测试

SAM3 已运行通过；只有需要复现或更换测试图像时才重跑。脚本要求传入与图像中目标匹配的具体单数英文类别，并在推理阶段使用 RTX 4090 支持的 BF16 autocast：

```bash
python scripts/smoke_sam3.py \
  --image data/smoke/scene.jpg \
  --checkpoint weights/sam3/sam3.pt \
  --prompt cup \
  --output-dir runs/smoke/sam3 \
  --report environment/sam3_smoke_report.json
```

将示例中的 `cup` 替换为测试图像中清晰存在的类别，例如 `bottle` 或 `can`。该测试只证明提示分割链路，不证明全量物体发现。

Qwen3-VL 单模型已通过；只有复现时才单独运行：

```bash
export HF_HOME="$PWD/weights/qwen"
export HF_HUB_CACHE="$HF_HOME/hub"

python scripts/smoke_qwen.py \
  --image data/smoke/scene.jpg \
  --model Qwen/Qwen3-VL-8B-Instruct-FP8 \
  --output-dir runs/smoke/qwen \
  --report environment/qwen_smoke_report.json
```

脚本默认读取 `HF_HUB_CACHE`，把模型缓存的 `refs/main` 解析到 `snapshots/<commit>`，再将该本地目录传给 Transformers；这避免仓库 ID 路径继续请求 Hub API。只有需要脚本自行联网取文件时才显式增加 `--allow-network`；正常冒烟不要使用该选项。

模型、依赖或服务器发生变化时，使用具体 SAM3 提示重新验证顺序运行：

```bash
bash scripts/run_server_smoke_tests.sh data/smoke/scene.jpg cup
```

将 `cup` 替换为图像中的实际类别。顺序脚本不再提供 `object` 默认值，以避免产生误导性失败。

统一入口会自行激活项目 Conda 环境并设置 `OMP_NUM_THREADS`、`HF_HOME` 和 `HF_HUB_CACHE`，随后依次运行两个模型和环境自检；新终端也无需手动逐条 `export`。日常 M1 开发无需重复冒烟，只有模型、依赖或服务器变化时才重跑。
