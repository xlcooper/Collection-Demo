# 服务器环境与模型冒烟测试指南

## 1. 目的

本指南用于在 AutoDL 服务器上创建可复现的项目环境，并分别验证 SAM3 与 Qwen3-VL 的真实推理链路。所有命令均在服务器仓库目录执行。

默认仓库位置：

```text
/root/autodl-tmp/Collection-Demo
```

默认 SAM3 权重：

```text
/root/autodl-tmp/Collection-Demo/weights/sam3/sam3.pt
```

## 2. 本批次交付物

| 文件 | 用途 |
|---|---|
| `environment.yml` | Python 3.12、PyTorch cu128、SAM3 与 Qwen 依赖事实源 |
| `scripts/setup_server_env.sh` | 在数据盘创建/更新 Conda 环境并重新自检 |
| `scripts/smoke_sam3.py` | 单张图像的 SAM3 真实推理测试 |
| `scripts/smoke_qwen.py` | 单张图像的 Qwen3-VL 结构化 JSON 测试 |
| `scripts/run_server_smoke_tests.sh` | 顺序运行两个模型并生成固定报告 |

Conda 环境默认创建在：

```text
.conda/envs/object-memory-demo
```

Qwen/Hugging Face 缓存默认保存在：

```text
weights/huggingface
```

上述目录以及运行图像产物均已被 Git 忽略。

## 3. 创建环境

建议在 `screen` 会话中运行，避免连接中断：

```bash
cd /root/autodl-tmp/Collection-Demo
git pull origin main
screen -S collection-env
bash scripts/setup_server_env.sh
```

脚本会：

1. 检查现有 SAM3 checkpoint；
2. 在数据盘创建或更新独立 Conda 环境；
3. 安装固定版本的 PyTorch cu128、SAM3 与 Qwen 依赖；
4. 创建被忽略的模型缓存和数据目录；
5. 使用当前环境重新生成 `environment/server_env_report.json`。

第一轮不安装 `flash-attn-3` 或 `cc_torch`，避免系统 nvcc 11.8 影响基础链路。

如果脚本返回非零值，环境报告仍会尽量保留。此时不要继续冒烟测试，先检查报告中的 `summary.issues`。

## 4. 准备冒烟图像

选择一张包含至少一个清晰独立物体的普通 JPG 或 PNG。测试图像不进入 Git，可放在服务器数据目录，例如：

```text
/root/autodl-tmp/Collection-Demo/data/smoke/scene.jpg
```

## 5. 顺序运行两个冒烟测试

```bash
cd /root/autodl-tmp/Collection-Demo
bash scripts/run_server_smoke_tests.sh \
  /root/autodl-tmp/Collection-Demo/data/smoke/scene.jpg \
  object
```

第二个参数 `object` 只是验证 SAM3 文本提示链路，不代表最终的“全量发现”策略。

运行器会启动两个独立 Python 进程：SAM3 结束并释放显存后，才会加载 Qwen3-VL。

## 6. 输出

建议提交至 Git 的小型报告：

```text
environment/server_env_report.json
environment/sam3_smoke_report.json
environment/qwen_smoke_report.json
```

被 Git 忽略的大型或临时产物：

```text
runs/smoke/<run_id>/sam3/*.png
runs/smoke/<run_id>/qwen/response.txt
weights/huggingface/**
.conda/**
```

## 7. 通过条件

### 环境

- 当前环境名为 `object-memory-demo`；
- Python 为 3.12；
- PyTorch CUDA 可用；
- SAM3 包可导入；
- SAM3 checkpoint 存在；
- 模型和数据目录可写。

### SAM3

- 报告状态为 `passed`；
- `proposal_count > 0`；
- 至少保存一个 mask；
- 报告包含加载时间、推理时间和显存峰值。

### Qwen3-VL

- 报告状态为 `passed`；
- 输出可解析为 JSON；
- 七个必填标注字段全部存在；
- 报告包含加载时间、推理时间和显存峰值。

## 8. 回传结果

运行完成后，在 CHANGELOG 顶部增加新的补丁版本摘要，再提交三份报告：

```bash
git add CHANGELOG.md \
  environment/server_env_report.json \
  environment/sam3_smoke_report.json \
  environment/qwen_smoke_report.json
git commit -m "chore: record server smoke results"
git push origin main
```

报告 push 后，本地 AI 首先 pull，再分析结果并决定是否进入 M1。
