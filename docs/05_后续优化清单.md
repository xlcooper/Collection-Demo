# 后续优化清单

> 本文档集中保存用户明确延后项、用户记录的后续想法、有证据但待定优先级的假设、已接受权衡和历史不处理项。它不是当前版本计划，也不用来判定当前实验是否通过。

## 管理规则

- 每项使用稳定 ID；普通版本升级不删除、重置或重新排号。
- 只记录用户已提出的后续想法、已明确延后的事项，或有实验证据但当前未排期的事项。
- 条目状态只在用户改变优先级、开始实施、实验证实或明确放弃时更新。
- 当前必须修复的阻断项仍写在 `AGENTS.md`；已发生事实和审计结论仍写在 `PROGRESS.md`。

## 用户明确延后

### FUT-MEM-001 观测信息增量筛选

- **状态**：暂缓；2026-08-02 用户确认当前处理没有问题。
- **记录依据**：用户先后提出“有效新视角不一定都要保存”的优化想法，并在 2026-08-02 明确当前暂不考虑。
- **当前行为**：候选有效且终态为 `new` 或 `existing` 时，直接保存 observation。
- **后续方向**：将“候选有效”、“属于已有对象”和“值得新增长期观测”拆开；只在新视角、外观、状态或身份证据有增量时追加长期观测。
- **权衡**：可减少重复和低信息视角，但也可能过早删掉后续身份判断所需的证据。

## 用户记录的后续想法

- **状态**：已记录为后续优化想法，未排期。
- **记录依据**：2026-07-31 用户提出优先保存差异化 crop、不在对象目录重复保存 overlay；v0.17.0 审计量化了实际重复空间。

## 当前接受的设计权衡

### FUT-BATCH-001 首轮4图批次权衡

- **状态**：保留当前4图设计，不自动拆单救援。
- **记录依据**：2026-07-31 用户明确要求保留4图批次设计和其 trade-off；v0.17.0 证实了批次成本收益与原子失败风险。
- **当前行为**：每批是一个完整结构化响应；任一内嵌字段违反 schema，整批不会生成可部分使用的结果。
- **后续方向**：只在有可比实验时评估批次大小或协议隔离方式。
- **权衡**：大批次降低调用和重复上下文成本，但会放大单字段错误的影响范围。

### FUT-DISC-001 首轮目标选择的召回与精度

- **当前行为**：首轮 Qwen 选择值得机械臂深入观察的独立物体，其文本概念决定 SAM3 的搜索范围。
