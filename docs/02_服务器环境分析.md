## 4. 模型部署决策

### 4.1 SAM3

- 使用官方 `facebook/sam3` 图像 checkpoint；
- 权重固定在服务器 `weights/sam3/sam3.pt`，不进入 Git；
- 源码固定到 `requirements-sam3.txt` 中记录的提交；
- 第一阶段只验证图像推理，不安装视频、训练或可选 CUDA 扩展；
- 通用提示 `object` 返回 0 proposals；M2 曾用显式类别列表验证文本提示链路，但该策略不满足当前“无需外界类别提示”的业务要求。M5-A v2 自动点网格已通过当前场景验收：3/3 个物体均被覆盖，保留候选由 12 降至 7，候选推理 7.183 秒、峰值显存 5390.59 MiB；少量剩余阴影交由 Qwen 判断。

### 4.2 Qwen3-VL

- 首选 `Qwen/Qwen3-VL-8B-Instruct-FP8`；
- Hugging Face 缓存根目录为 `weights/qwen`；
- `HF_HUB_CACHE` 固定为 `weights/qwen/hub`，不是系统默认缓存目录；
- MVP 使用 Transformers 直接推理；
- 模型下载与推理解耦：冒烟和正式推理先把缓存引用解析为本地 snapshot 目录，再交给 Transformers；
- 只有 8B FP8 在真实加载或推理中失败时，才回退到 `Qwen/Qwen3-VL-4B-Instruct`；
- 不提前安装 vLLM、SGLang 或 Thinking 模型。

### 4.3 顺序运行

```text
SAM3：图像 → proposal / mask / crop / overlay → 保存并释放显存
Qwen：单张源图的全部候选 + 全部 active 对象卡片及参考图 → 批量判断、标注、归类 → 保存并释放显存
```

RTX 4090 24 GiB 不承担两个模型同时驻留。这个限制应保留到真实显存数据证明可以安全调整为止。
